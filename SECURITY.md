# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| latest commit on `main` | yes |
| older | no |

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately with GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Include: affected file, a description, steps to reproduce, and the impact you see. Never include real secrets or personal data in a report; describe where they appear instead.

## What to expect

This is a one-person project maintained on a best-effort basis. The maintainer aims to send an initial response within 14 days. A fix date is not promised.

## Scope

In scope: the generation and validation scripts and the generated HTML page. Out of scope: the accuracy of third-party model information (report factual corrections as a normal issue with a source link).

If you find personal data that was missed in this repository (for example a contact address copied from a third-party page), report it through the private channel above.
